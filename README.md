# VisaFlow

VisaFlow — Telegram Mini App для самостоятельной подготовки визовой заявки: от персонального checklist и проверки документов до уведомлений о слотах и сроках.

Первая версия поддерживает туристические визы Италии, Испании и Японии. Мониторинг слотов для Италии является экспериментальной функцией и включается только при допустимости автоматических проверок.

## Принципы MVP

- Разработка, автотесты и учебная демонстрация используют только синтетические документы.
- Реальные документы допускаются только в закрытом пилоте после проверки безопасности.
- Никакого обхода CAPTCHA или других защит визовых порталов.
- Решение консульства не предсказывается; система показывает найденные несоответствия и их основания.
